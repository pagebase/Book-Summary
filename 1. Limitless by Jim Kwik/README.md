# 4 Villains

1. `Digital deluge`: Avoid unending flood of information.
2. `Digital distraction`: Avoid using phone or electronic thing while working deep.
3. `Digital dementia`
4. `Digital deduction`: Use your brain for remembering phone number, street name, social media passwords.
